1. Install python on your system with the setup file
	# Download python throught this link: https://www.python.org/ftp/python/3.12.1/python-3.12.1-amd64.exe

2. Open cmd and paste "python --version" into the terminal to verify installation 

3. Check if the python package installer(pip) is also installed by pasting "pip --version" into the terminal

4. If pip is not installed paste "python -m ensurepip --default-pip" into the terminal
